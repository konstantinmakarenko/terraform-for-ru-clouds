# terraform-for-ru-clouds

Проект находится в разработке.

`terraform-for-ru-clouds` - это набор Terraform-конфигураций для создания учебной сетевой инфраструктуры в российских облаках: Yandex Cloud, Selectel и Cloud.ru.

## Назначение

Проект моделирует инфраструктуру из пяти виртуальных машин в трёх связанных сетях:

- `r1` и `r2` - маршрутизаторы;
- `ws11`, `ws21`, `ws22` - рабочие станции;
- подсети `network-a`, `network-b`, `network-c`;
- маршруты между подсетями;
- публичный доступ там, где он нужен для входа и проверки.

## Поддерживаемые облака

- `yandexcloud/` - конфигурация для Yandex Cloud.
- `selectel/` - конфигурация для Selectel/OpenStack.
- `cloudru/` - конфигурация для Cloud.ru.

В Cloud.ru часть конфигурации может требовать дополнительной проверки provider-а и актуальных настроек платформы.

## Структура

- `network.tf` - сети, подсети, маршрутизаторы и маршруты.
- `compute.tf` - виртуальные машины и привязки к сетям.
- `providers.tf` или `versions.tf` - Terraform provider-ы.
- `variables.tf` - входные переменные.
- `outputs.tf` - полезные выходные значения.
- `terraform.tfvars.example` - пример локальной конфигурации.

## Требования

- Terraform.
- Доступ к выбранному облачному провайдеру.
- Публичный SSH-ключ.
- Понимание стоимости создаваемых ресурсов.

## Запуск

Выполняйте команды внутри папки конкретного провайдера:

```bash
cp terraform.tfvars.example terraform.tfvars
terraform init
terraform fmt
terraform validate
terraform plan
terraform apply
```

Перед `apply` внимательно проверьте план: количество ВМ, диски, публичные IP, сети и маршруты.

## Ограничения

Проект учебный и не является готовым production-шаблоном. Перед реальным использованием нужно отдельно проверить:

- правила входящего и исходящего трафика;
- маршрутизацию;
- хранение Terraform state;
- управление SSH-ключами;
- стоимость ресурсов;
- актуальность provider-ов.

## Безопасность

Не храните в репозитории реальные `terraform.tfvars`, приватные ключи, токены, state-файлы и внутренние схемы доступа.
