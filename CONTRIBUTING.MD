# Contributing

Спасибо за интерес к `terraform-for-ru-clouds`. Здесь собраны независимые Terraform-конфигурации для нескольких облаков, поэтому изменения лучше делать точечно и отдельно проверять для каждого провайдера.

## Перед началом

- Выберите конкретного провайдера: `yandexcloud`, `selectel` или `cloudru`.
- Не смешивайте изменения разных провайдеров без необходимости.
- Не добавляйте реальные секреты и локальные `terraform.tfvars`.

## Проверки

Для изменённой папки выполните:

```bash
terraform fmt
terraform validate
terraform plan
```

Если менялись несколько папок, проверьте каждую отдельно.

## Что обновлять вместе с кодом

- При добавлении переменной обновляйте `variables.tf` и `terraform.tfvars.example`.
- При изменении создаваемых ресурсов обновляйте `README.MD`, если меняется сценарий использования.
- При изменении выходных значений обновляйте `outputs.tf` и описание, где это важно.

## Описание pull request

Укажите:

- какой провайдер затронут;
- какие ресурсы создаются, изменяются или удаляются;
- какие проверки выполнены;
- есть ли риск дополнительных расходов.
